# Profile link hub and UTM scheme

Hub: `https://hoho-tour.com/go/` (EN) and `https://hoho-tour.com/kr/go/` (KR).
Generated by `python3 tools/build_go.py` from `content/blog/*.md`. Re-run after adding a guide.

## Links to put in each place

| Where | Link |
|---|---|
| Instagram / TikTok / YouTube bio | `https://hoho-tour.com/go/?utm_source=instagram&utm_medium=bio` |
| One Short / Reel (caption or pinned comment) | `https://hoho-tour.com/go/?utm_source=<platform>&utm_medium=<format>&utm_campaign=<destination>&utm_content=<id>` |

## Parameters

- `utm_source`: instagram, youtube, tiktok
- `utm_medium`: bio, short, reel, photocard
- `utm_campaign`: destination key = first word of the guide slug (danyang, busan, jeju, seoul, gyeongju ...)
- `utm_content`: one id per post, e.g. `danyang-s01-v4` (destination, format letter+number, version)

## What the hub does

- Forwards every utm_* value onto the guide links, so the guide page visit carries the same tags.
- If `utm_campaign` matches a destination, that destination's guides show first under "From the video".
- With no utm values, guide links carry `utm_source=bio&utm_medium=hub&utm_campaign=<destination>`.
- Page is `noindex`.

## Reading the numbers

Tags only show up in an analytics tool. The site's Cloudflare Web Analytics token (`cfAnalyticsToken` in hugo.yaml) is empty today, so nothing records visits by UTM until that is switched on.
